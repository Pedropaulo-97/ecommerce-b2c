# 🛒 E-Commerce B2C (Java)

---

## 🚀 Sobre o Projeto
Este projeto visa construir o back-end e a infraestrutura de um e-commerce voltado para o consumidor final (B2C). O foco inicial é garantir uma base sólida de regras de negócio (gestão de estoque, catálogo de produtos, cálculo de carrinho e processamento de pedidos).

---

## 🛠️ Tecnologias
* **Linguagem:** Java 25
* **Gerenciador de Dependências:** Maven

---

## 🚧 Status do projeto
Em construção — este é um projeto de estudo em evolução contínua, construído fase a fase conforme novos conceitos são aprendidos e aplicados.

---

## 🗺️ Roadmap (planejado)

O projeto evolui em etapas, e cada uma é aplicada diretamente no código.

1. **Setup e fluxo profissional**: Git/GitHub, Maven, JDK 25 e Pull Requests
2. **Fundamentos de Java e OOP**: domínio do e-commerce em Java puro (produto, cliente, pedido)
3. **Collections, exceções e testes**: regras de carrinho e desconto com testes unitários
4. **SQL e persistência**: PostgreSQL, Docker Compose e camadas da aplicação
5. **API REST com Spring Boot**: MVP de catálogo, com validação, migrations e documentação
6. **Segurança, pedidos e estoque**: autenticação, checkout e controle de estoque
7. **Entrega e qualidade**: CI com GitHub Actions, Docker e deploy

Depois do MVP: cache, mensageria, observabilidade e evolução da arquitetura.
