# 🛒 E-Commerce B2C (Java)

---

## 🚀 Sobre o Projeto
Este projeto visa construir o back-end e a infraestrutura de um e-commerce voltado para o consumidor final (B2C). O foco inicial é garantir uma base sólida de regras de negócio (gestão de estoque, catálogo de produtos, cálculo de carrinho e processamento de pedidos).

---

## 🛠️ Tecnologias
* **Linguagem:** Java 25
* **Gerenciador de Dependências:** Maven

---

## 🚧 Status do projeto
Em construção — este é um projeto de estudo em evolução contínua, construído fase a fase conforme novos conceitos são aprendidos e aplicados.
